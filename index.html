核心特性

为什么选择 tpl-workspace

不绑定业务领域，沉淀多端通用能力。接入业务即可快速产出覆盖五端的完整产品。

多端覆盖

用户端 Web / Android / HarmonyOS / 微信小程序，加 Web 管理后台，一套架构贯穿五端。

双后端服务

用户端 API（独立 Spring Boot 4.1）+ 管理端（RuoYi-Vue-Plus），职责清晰、可独立演进。

统一设计系统

一套 Design Tokens（色彩 / 字体 / 间距）跨端复用，保证多端视觉一致，避免视觉漂移。

国际化

三语言（zh-CN / en-US / zh-TW）语料单一事实源，脚本自动同步到各端。

主题支持

light / dark / system 三态主题，深浅色皮肤联动，尊重系统偏好。

部署编排

Docker Compose 一键编排 PostgreSQL / Redis / 双后端 / 前端 / Nginx 网关。

系统架构

清晰的请求与数据流

各端客户端经 Nginx 网关路由 → 用户端请求进入 tpl-app-api，管理端请求进入 tpl-manage → 统一持久化到 PostgreSQL / Redis / MinIO。

↓

/web/ → 用户端 /manage/ → 管理端 /api/ → 用户端 API
↓
双后端服务
tpl-app-api · 用户端 API tpl-manage · 管理后台
↓
数据层
PostgreSQL Redis MinIO
快速开始

三步跑起来

克隆仓库 → 一键启动全套服务 → 访问。

  1. 1

    克隆仓库（含子模块）

    git clone --recurse-submodules <repo-url> && cd tpl-workspace
  2. 2

    一键启动全套服务（数据库 / 缓存 / 双后端 / 前端 / 网关）

    docker compose -f deploy/docker-compose.yml up -d --build
  3. 3

    访问各端

    # 用户端 Web：  http://localhost:38088/web/
# 管理后台：    http://localhost:38088/manage/
